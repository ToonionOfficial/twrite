# API Reference

The full type- and function-level reference, generated from the doc comments
by `rustdoc`:

- [`twrite`](api/twrite/index.html): facade: buffer, hooks, GPUI editor
- [`twrite-core`](api/twrite_core/index.html): headless buffer, syntax,
  movement, hooks, prompt, search
- [`twrite-gpui`](api/twrite_gpui/index.html): canvas, theme, config, editor

Rebuilt on every `main` push, so it always matches the guides above. Start
with `twrite_core::{EditorBuffer, EditorHook, HookContext, PromptState}` and
`twrite_gpui::Editor`.
